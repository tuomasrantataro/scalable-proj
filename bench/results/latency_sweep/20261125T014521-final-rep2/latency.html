Advisory latency vs. input rate

Latency = window fired (the watermark passed the window's end) → advisory received by a Kafka consumer. Both axes are logarithmic. Labels above the plot are the replay speed-up (1× = the feed's real pace). Each point replays the same slice into a fresh job, subscribed to every symbol. The first window close after the job starts (cold start) is left out; it is in the table.
